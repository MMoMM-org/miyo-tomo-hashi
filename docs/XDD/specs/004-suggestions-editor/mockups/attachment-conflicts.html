Attachments & conflict remedy

Each card gains an Attachments section built from suggestions[].attachments. An attachment whose destination is taken shows Tomo's attachment_conflicts entry inline, with the remedy and the rename target (folder and name). To try the name field, type karte#1938.png, a:b.png or karte.png, or clear it.

Rules shown

  • Every card lists all of its attachments (any number), worthy and suppressed alike. An attachment without a conflict is read-only and shows where it goes.
  • A conflict is keyed by source. Every card that embeds the file shows the same box, and an edit on one card updates all of them. Hover shared by N notes to see which notes.
  • Remedy: rename (move to a chosen folder under a chosen name), keep_in_inbox, or ignore (no move; the embed resolves to the existing file). The default is what Tomo emitted.
  • The target folder is picker-only: existing vault folders, the inbox and everything below it excluded. There's no free-text folder. A user who needs a new folder creates it in Obsidian first. Moving to a free folder can resolve the conflict without changing the name. On the wire this is proposed_dir (Tomo spec 039, wire v4). Picking the default folder back writes null.
  • No free name + a picked folder (scenario 2, stadtplan.pdf): the name field is pre-filled with the original basename, visibly, so it reaches the wire as proposed_name. Tomo never fills in a name itself.
  • The name sanitises visibly. Tomo's 10 forbidden characters \ / : * ? " < > | + NUL and the link-breakers # ^ [ ], the template sequences {{ / <% and control characters become -, and leading/trailing whitespace is trimmed. The saved name is shown under the field. A blank name is refused inline. If folder + name is also taken, you get a warning but aren't blocked, because Tomo's Pass 2 reports that case independently. If the final name also exists anywhere else in the vault, an info line says the embed will carry the full path: Obsidian resolves an ambiguous bare embed to a copy in the note's own folder, or else to one vault-wide winner (measured 2026-10-12).
  • Switching away from Rename keeps the typed folder and name on the wire, so switching back restores them. Tomo ignores both unless the remedy is rename.
  • If no owning note is filed (all owners skipped, or suppressed without Force Atomic), the remedy has no effect. The whole box greys out, and only the owners' own controls (e.g. Force Atomic) stay live.
